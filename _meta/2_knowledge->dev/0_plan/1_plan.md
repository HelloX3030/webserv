## reading strategy

### For RFCs
- **Pass 1**: Skim structure, see sections
- **Pass 2**: Detailed reading, take notes
- **Pass 3**: Reference during implementation
- Note every MUST, SHOULD, MAY (RFC 2119 keywords)
- Learn ABNF grammar notation

### For Stevens
- **Don't just read** - trace examples by hand
- Draw diagrams of socket states
- Ask "why" for every design choice
- Code small examples to verify understanding

### For Reference Implementations
- **Don't read linearly** - trace specific features
- Start with simple modules first
- Ask: "Why this data structure? Why this algorithm?"
- Draw architecture diagrams
