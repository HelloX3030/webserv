# kleene star

the closure operation over formal languages.
denotes zero or more repetitions of a pattern.


---


## essence

given a set of strings L, the Kleene star L* is
the set of all strings formed by concatenating
zero or more strings from L.
```
L* = { ε } ∪ L ∪ LL ∪ LLL ∪ ...
```

where ε is the empty string.

the operation is named after Stephen Cole Kleene (1909–1994),
who introduced it in his 1956 paper on nerve net representations.


---


## formal definition

for a language L over alphabet Σ:
```
L⁰ = { ε }
Lⁿ = L · Lⁿ⁻¹        (concatenation)
L* = ⋃_{n≥0} Lⁿ
```

equivalently, L* is the smallest language containing ε
and closed under concatenation with L.


---


## in ABNF

RFC 5234 uses `*` as prefix operator:
```abnf
*element        ; zero or more
1*element       ; one or more (Kleene plus)
3*5element      ; three to five
```

example from HTTP grammar:
```abnf
*( header-field CRLF )
```

zero or more header lines. the Kleene star makes the repetition
unbounded yet expressible finitely — the grammar is finite,
the language it generates is infinite.


---


## why "star"?

the asterisk notation originated in Kleene's work on regular events.
it visually suggests "any number" — a wildcard.
the superscript notation L* parallels exponentiation,
where repeated multiplication becomes a single symbol.


---


## relation to regular languages

a language is regular iff it can be expressed using:
1. union (alternation)
2. concatenation
3. Kleene star

these are the 3 operations that define the regular languages.
Kleene's theorem: a language is regular iff it is recognised
by a finite automaton iff it is generated by a regular expression.

the star is what distinguishes regular expressions from
simple pattern matching — it introduces unbounded iteration
without requiring unbounded memory (no stack, no recursion).


---


## kleene plus

L⁺ = L · L* = LL*

one or more repetitions. equivalent to L⁺ = L* − { ε }.

ABNF: `1*element`
regex: `+` suffix


---


## language perspectives

### Agda

repetition modelled as a recursive type:
```agda
data List (A : Set) : Set where
  []  : List A
  _∷_ : A → List A → List A
```

`List A` is the Kleene star over the singleton language {a} for each a : A.
the type is inductively defined — corresponds to L* being
the least fixed point of X = { ε } ∪ L · X.


### Haskell
```haskell
-- Kleene star as list
many :: Parser a -> Parser [a]
many p = many1 p <|> pure []

-- Kleene plus
many1 :: Parser a -> Parser [a]
many1 p = (:) <$> p <*> many p
```

parser combinators make the star explicit:
`many` is star, `many1` is plus.


### Rust (nom)
```rust
many0(parser)   // zero or more
many1(parser)   // one or more
```

same pattern. the operation is fundamental enough
that every parsing library provides it primitively.

## in the HTTP parser

the header section uses Kleene star:
```abnf
*( header-field CRLF )
```

implementation: a loop that continues while header lines are found.
no stack required — the grammar is regular,
the "parser" is effectively a scanner with phase state.
```cpp
// Kleene star over header lines
while (phase_ == ParsePhase::HEADERS)
{
    PhaseResult r = parse_header_line();
    if (r == PhaseResult::NeedMore) return Incomplete;
    if (r == PhaseResult::Failed) return Failed;
    // else Advanced — loop continues (star)
}
```

the loop is the Kleene star made operational.
