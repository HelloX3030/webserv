uploads

Drop a file in, fetch it back out.

This demo stores raw bytes under /upload/<filename> and lets you open them immediately afterward.

Upload

Open sample file

What happens

  • The browser sends the raw file body to /upload/<filename>.
  • The server writes it to disk.
  • The same path can be used with GET to retrieve it.

curl proof

curl --data-binary @/path/to/file.txt http://127.0.0.1:8080/upload/file.txt
curl http://127.0.0.1:8080/upload/file.txt
