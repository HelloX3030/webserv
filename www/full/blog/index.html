Building a tiny yet feature-rich web server

One config can orchestrate static pages, redirects, uploads, CGI, cookies, error pages, and virtual hosts.

Published: 2026-04-07

Why this post exists

This page is part of config/valid/full.conf, designed to prove all major project features work in one runnable setup.

Features you can verify right now

  • Redirect: /old → /blog/
  • Uploads: /uploads/ + /upload/<filename>
  • Cookies via CGI: /cookies/
  • Python CGI: /cgi-python/env.py
  • Bash CGI: /cgi-bash/env.sh
  • Custom error pages: trigger 404 on a missing path
