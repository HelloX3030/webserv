multi-server.conf: alpha

Host route matched: alpha.localhost.

How to test without editing /etc/hosts

Use curl with an explicit Host header:

curl -H "Host: alpha.localhost" http://127.0.0.1:8080/
curl -H "Host: beta.localhost"  http://127.0.0.1:8080/

How to test in a browser

Browsers use the hostname from the URL as Host header. Add local mappings:

127.0.0.1 alpha.localhost
127.0.0.1 beta.localhost

Then open:

http://alpha.localhost:8080/
http://beta.localhost:8080/

Note: editing /etc/hosts needs elevated privileges on Linux. Curl tests do not.
