You started config/valid/autoindex_test.conf. This config is primarily for integration tests.

Routes in this config

  • /auto_on/ → autoindex on
  • /auto_off/ → autoindex off, no index → 404
  • /auto_off_index/ → autoindex off + index index.html

Important

These routes point to temporary test directories under www/full/itest_autoindex_*. If tests have not created those directories/files yet, some routes will return 404.

For a stable always-populated demo, use config/valid/autoindex.conf instead.
