cgi-bash.conf demo

This page is static. The CGI endpoint is under /cgi-bin/.

GET example:

curl "http://127.0.0.1:8080/cgi-bin/hello.sh?name=Lukas"

POST example:

curl -X POST --data "hello from post" http://127.0.0.1:8080/cgi-bin/echo.sh
