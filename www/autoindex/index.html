Autoindex demo

This config exists to demonstrate directory handling when a request maps to a folder. It uses config/valid/autoindex.conf.

/auto_on/

autoindex on. If no index file exists, the server returns an HTML directory listing.

  • Expected: 200 + Content-Type: text/html

/auto_off/

autoindex off. If no index file exists, directory access is forbidden.

  • Expected: 403 Forbidden

/auto_off_index/

autoindex off but index index.html is configured. Index files take precedence over autoindex.

  • Expected: 200 serving index.html when present

How to try it

Run:

  • make
  • ./webserv config/valid/autoindex.conf
  • Open http://127.0.0.1:8080/

Tip: the integration tests dynamically create directories/files under www/full/itest_autoindex_*, so these routes may appear empty unless tests (or you) create files there.
