cgi-python.conf demo

This page is static. The CGI scripts live under /cgi-bin/.

Quick curl tests

curl "http://127.0.0.1:8080/cgi-bin/hello.py?name=Lukas"
curl -X POST --data "hello from post" http://127.0.0.1:8080/cgi-bin/echo.py

Browser tests

/cgi-bin/hello.py?name=browser
/cgi-bin/echo.py

What to look for

  • REQUEST_METHOD changes between GET and POST.
  • QUERY_STRING is filled for the GET example.
  • CONTENT_LENGTH is filled for the POST example.
  • The body from POST is printed back by the CGI script.
